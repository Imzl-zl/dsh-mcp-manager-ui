# 技能管理 + 技能市场

本插件同时有两个能力面：**MCP** 与**技能**。面板顶部的能力层枚举用来切换，两者共享同一个悬浮窗与侧栏入口。

技能能力面解决的是 DSH 自带技能目录**看不到**的那些事：

- 技能到底装在哪个作用域（同名技能跨作用域是合法配置，但模型只会收到生效的那一份）；
- 为什么某个技能**不生效**（frontmatter 非法时宿主只 `warn` 后跳过，用户和模型都看不到那条警告）；
- 哪些技能被**停用**了（改名后宿主目录里直接消失，模型和面板都看不见它）；
- 哪些技能**能装、哪些不能装**（许可门禁）。

## 打开技能面板

点右下角悬浮按钮或侧栏「MCP」入口打开面板，再点顶部的能力层「**技能**」。

面板分两个模式：

| 模式 | 用途 |
|---|---|
| **管理** | 左列表 + 右详情。看本机已有的技能，启停、删除、查看正文与诊断 |
| **市场** | 卡片网格。内置精选目录（离线可用）+ skills.sh 搜索补充 |

**作用域只在管理模式出现**：市场是远端目录，装上之后才有作用域，所以安装时才会问你装到哪。

## 作用域

技能可以装在多个位置，DSH 按优先级依次查找。面板里的作用域候选**来自实际发现的位置**，不是写死的清单——本机就可能没有 `~/.dsh/skills`，技能全在 `~/.agents/skills`。

| 优先级 | 位置 | 说明 |
|---|---|---|
| 100 | `<项目>/.dsh/skills` | 项目级 |
| 200 | `<项目>/.agents/skills` | 项目级 |
| 300 | 自定义目录 | 由宿主配置 |
| 400 | `<DSH_HOME>/skills` | 全局 |
| 500 | `<AGENTS_HOME>/skills` | 全局 |
| 600 | 内置（bundled） | **只读**，不可启停/删除 |

同名技能出现在多个作用域时，面板会标出**哪一份生效、哪一份被遮蔽**——被遮蔽的那份模型收不到，但你确实装了它。

## 启用与停用

DSH 的技能没有「disabled」字段（MCP 有，技能没有），所以启停的做法是把 `SKILL.md` 改名为 `SKILL.md.disabled`：

- 停用后技能从宿主目录里**消失**（宿主按固定路径读 `SKILL.md`，读不到就跳过），
  所以已停用的技能由本面板**自己扫描** `.disabled` 得出，否则你根本看不到它、也没法再启用；
- 内置（bundled）技能只读，不可启停或删除。

## 安装技能

市场里点「安装」会先给你一份披露（安装确认弹窗）：

- **技能正文会作为指令进入模型上下文** —— 这是技能的工作原理，也是它最主要的信任面；
- 是否**含可执行脚本**（`scripts/` 目录）；
- 技能**声明**的工具权限（`allowed-tools`）。注意 DSH 宿主并**不**强制这个字段，
  它只是作者声明的意图——正因如此才要如实披露，让你自己判断。

确认后选择装到哪个作用域（全局或某个项目），再执行安装。支持三种来源：

| 来源 | 说明 |
|---|---|
| 单个 `.md` 文件 | 装成扁平技能 `<name>.md` |
| 技能目录 | 装成目录捆绑 `<name>/`，连带 `scripts/`、`references/` 等资源 |
| 压缩包 | `.zip` / `.tar` / `.tar.gz` / `.tgz`，按**魔数**识别（下载链接可以不带扩展名） |

安装按 frontmatter 里的 `name` 落盘（不是文件名）——宿主就是这么认定技能身份的。
同名技能已存在时会**拒绝而不是覆盖**；压缩包里若有多个技能则拒绝（不替你猜装哪个）。

## 许可门禁

市场对**每一条技能**单独判定许可，**不按仓库聚合**。这不是保守，是必须的：同一个仓库里既有 Apache-2.0 的技能，也有禁止「在服务之外保留副本」的专有许可技能。

- **不可安装**的条目仍然会显示，并说明理由——你搜 `pdf` 时应该知道「为什么没有」，
  而不是以为面板漏了；
- 未声明许可 = 没有授权 = 不可安装（不会当作「随便用」）；
- 声明与实际冲突时**以技能目录里的许可文件为准**，并在卡片上标出「声明不一致」。

**收录 ≠ 背书。** 技能正文会作为指令进入模型上下文，且可能含可执行脚本。本目录只做来源白名单与许可校验，**不做安全审查**——安装前请确认来源可信。

## 搜索

- 内置目录**离线可用**，首屏不依赖网络；
- skills.sh 搜索是**补充**：结果按来源白名单过滤。skills.sh 的 `source` 字段**不可信**
  （实测存在仿冒同名来源），所以只有核实过的来源会显示；
- 搜索失败会静默降级成「仅内置目录」，不会让市场页打不开；
- 远端搜索结果**不做**许可核实，因此默认不可直接安装——请先确认来源与许可。
